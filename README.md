# Reconnaissance-Footprinting-Network-Scanning-Assessment
 
## Overview
 
This repository contains the practical activities completed during Week 2 of the Networkwalks Cybersecurity & Ethical Hacking Internship Program.
 
The objective of these exercises was to gain hands-on experience with reconnaissance, Open-Source Intelligence (OSINT), footprinting, and network scanning techniques used during the early stages of a penetration test.
 
All activities were performed in authorized environments for educational purposes only.
 
---
